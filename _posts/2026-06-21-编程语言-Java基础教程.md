### 执行命令解析?
以上我们使用了两个命?**javac** ?**java**?

**javac** 后面跟着的是java文件的文件名，例?HelloWorld.java?
该命令用于将 java 源文件编译为 class 字节码文件，如： **javac HelloWorld.java**?



运行javac命令后，如果成功编译没有错误的话，会出现一?HelloWorld.class 的文件?

**java** 后面跟着的是java文件中的类名,例如 HelloWorld 就是类名，如: java HelloWorld?

**注意**：java命令后面不要?class?
