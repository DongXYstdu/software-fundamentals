## 字符串相关

### 题 1：反转字符串

```python
def reverseString(s):
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
```

**关键**：双指针，O(n) 时间，O(1) 空间。

### 题 2：有效的字母异位词

**判断两个字符串是否由相同字母组成（只是顺序不同）**

```python
def isAnagram(s, t):
    if len(s) != len(t):
        return False
    count = [0] * 26
    for c in s:
        count[ord(c) - ord('a')] += 1
    for c in t:
        count[ord(c) - ord('a')] -= 1
        if count[ord(c) - ord('a')] < 0:
            return False
    return True
```

**复杂度**：O(n) 时间，O(1) 空间（固定大小数组）。

### 题 3：最长回文子串

**思路**：中心扩展法。从每个字符（或两个字符之间）向两边扩展，找最长回文。

```python
def longestPalindrome(s):
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return s[left + 1:right]  # 注意：退出循环时边界不包含在内

    result = ""
    for i in range(len(s)):
        # 奇数长度中心：i
        odd = expand(i, i)
        # 偶数长度中心：i 和 i+1 之间
        even = expand(i, i + 1)
        result = max(result, odd, even, key=len)
    return result
```

**复杂度**：O(n²) 时间，O(1) 空间。

## 数组相关

### 题 4：移动零

**把数组中的 0 都移到末尾，保持非零元素的相对顺序**

```python
def moveZeroes(nums):
    slow = 0  # 下一个非零元素应该放的位置
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
```

**思路**：双指针。slow 指向"应该放非零元素的位置"，fast 遍历找非零元素。

### 题 5：两数之和

**给定数组和目标值，找两个数的下标使它们之和等于目标值**

```python
def twoSum(nums, target):
    seen = {}  # 值 → 索引
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

**复杂度**：O(n) 时间，O(n) 空间。

**对比暴力法**：双重循环 O(n²) 时间，O(1) 空间。哈希表是典型的"空间换时间"。

### 题 6：三数之和

**找出数组中所有不重复的三元组，使它们之和 = 0**

```python
def threeSum(nums):
    nums.sort()
    result = []
    n = len(nums)

    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # 跳过重复
        left, right = i + 1, n - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                # 跳过重复
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1

    return result
```

**思路**：排序 + 双指针。固定一个数，在剩余部分用两指针找另外两个数。

**复杂度**：O(n²) 时间，O(1) 空间（不算输出）。

## 链表相关

### 题 7：反转链表

```python
def reverseList(head):
    prev = None
    curr = head
    while curr:
        next_node = curr.next  # 保存下一个
        curr.next = prev       # 反转指针
        prev = curr            # prev 前进
        curr = next_node       # curr 前进
    return prev
```

**关键**：三个指针。画图看最清楚。

### 题 8：环形链表（判断是否有环）

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

**快慢指针**：如果有环，快的一定会追上慢的（类似跑步套圈）。

### 题 9：相交链表（找两个链表的交点）

```python
def getIntersectionNode(headA, headB):
    if not headA or not headB:
        return None
    pA, pB = headA, headB
    while pA != pB:
        pA = pA.next if pA else headB
        pB = pB.next if pB else headA
    return pA
```

**思路**：指针 A 走完 A 链表走 B 链表，指针 B 走完 B 链表走 A 链表。如果相交，它们会在交点相遇（都走了相同长度）；如果不相交，最终都为 null，也会相遇。

### 题 10：合并两个有序链表

```python
def mergeTwoLists(l1, l2):
    dummy = ListNode(0)
    curr = dummy
    while l1 and l2:
        if l1.val < l2.val:
            curr.next = l1
            l1 = l1.next
        else:
            curr.next = l2
            l2 = l2.next
        curr = curr.next
    curr.next = l1 if l1 else l2
    return dummy.next
```

**思路**：虚拟头节点 + 两个指针，谁小取谁。

## 栈/队列相关

### 题 11：有效的括号

```python
def isValid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in '([{':
            stack.append(c)
        else:
            if not stack or stack[-1] != pairs[c]:
                return False
            stack.pop()
    return len(stack) == 0
```

**关键**：遇到左括号入栈，遇到右括号检查栈顶是否匹配。

### 题 12：用两个栈实现队列

```python
class MyQueue:
    def __init__(self):
        self.in_stack = []   # 写入栈
        self.out_stack = []  # 读出栈

    def push(self, x):
        self.in_stack.append(x)

    def pop(self):
        if not self.out_stack:  # 读出栈空时，把写入栈倒过来
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack.pop()

    def peek(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack
```

**思路**：入栈始终往 in_stack 加。出栈时如果 out_stack 空，把 in_stack 全部 pop 到 out_stack（顺序就翻转了）。

### 题 13：最小栈（支持 getMin 的栈）

```python
class MinStack:
    def __init__(self):
        self.stack = []      # 存实际值
        self.min_stack = []  # 存当前最小值

    def push(self, val):
        self.stack.append(val)
        # 新的最小值 = min(当前最小值, 新值)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)
        else:
            self.min_stack.append(self.min_stack[-1])

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

**思路**：用两个栈，一个存值，一个存"截至当前位置的最小值"。

## 二叉树相关

### 题 14：二叉树的最大深度

```python
def maxDepth(root):
    if not root:
        return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
```

**思路**：递归。空树深度 0，否则 = 1 + max(左子树深度, 右子树深度)。

### 题 15：验证二叉搜索树（BST）

```python
def isValidBST(root, low=float('-inf'), high=float('inf')):
    if not root:
        return True
    if not (low < root.val < high):
        return False
    # 左子树：所有值 < root.val
    # 右子树：所有值 > root.val
    return (isValidBST(root.left, low, root.val)
            and isValidBST(root.right, root.val, high))
```

**关键**：不能只判断 `root.left.val < root.val < root.right.val`，还要保证**整个左子树的所有值都 < root.val**。

### 题 16：对称二叉树

```python
def isSymmetric(root):
    def isMirror(left, right):
        if not left and not right:
            return True
        if not left or not right:
            return False
        return (left.val == right.val
                and isMirror(left.left, right.right)
                and isMirror(left.right, right.left))

    return isMirror(root.left, root.right) if root else True
```

**思路**：判断左子树和右子树是否互为镜像。

### 题 17：二叉树的层序遍历

```python
from collections import deque

def levelOrder(root):
    if not root:
        return []
    result = []
    queue = deque([root])
    while queue:
        level = []
        level_size = len(queue)
        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```

**思路**：BFS。每一层开始时记录当前队列长度，只处理这一层的节点。

## 动态规划相关

### 题 18：爬楼梯

**每次可以爬 1 或 2 级台阶，n 级台阶有多少种爬法？**

```python
def climbStairs(n):
    if n <= 2:
        return n
    # dp[i] = 爬 i 级台阶的方法数
    # dp[i] = dp[i-1] + dp[i-2]（最后一步爬 1 或者最后一步爬 2）
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

**本质**：斐波那契数列。

**优化**：只需要前两个数，不需要整个数组 → O(1) 空间。

### 题 19：最大子数组和（Kadane 算法）

**找出数组中最大的连续子数组之和**

```python
def maxSubArray(nums):
    # dp[i] = 以 i 结尾的最大子数组和
    # dp[i] = max(nums[i], dp[i-1] + nums[i])
    result = curr_max = nums[0]
    for num in nums[1:]:
        curr_max = max(num, curr_max + num)  # 要么从自己开始，要么接在前面
        result = max(result, curr_max)
    return result
```

**复杂度**：O(n) 时间，O(1) 空间。

### 题 20：打家劫舍

**不能偷相邻的房子，求最大金额**

```python
def rob(nums):
    # dp[i] = 考虑前 i 个房子的最大金额
    # dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    #        = max(不偷第 i 个, 偷第 i 个)
    if len(nums) == 1:
        return nums[0]
    prev_prev, prev = nums[0], max(nums[0], nums[1])
    for i in range(2, len(nums)):
        curr = max(prev, prev_prev + nums[i])
        prev_prev, prev = prev, curr
    return prev
```

**思路**：对每个房子，要么偷（加上前前个的最大值），要么不偷（等于前一个的最大值）。

## 排序与查找

### 题 21：二分查找

```python
def binarySearch(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2  # 避免溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1  # 没找到
```

**要点**：
- `mid = left + (right - left) // 2`，不要 `(left + right) // 2`（可能溢出）
- 循环条件是 `<=`，不是 `<`

### 题 22：快速排序

```python
def quickSort(arr, left, right):
    if left < right:
        pivot_index = partition(arr, left, right)
        quickSort(arr, left, pivot_index - 1)
        quickSort(arr, pivot_index + 1, right)

def partition(arr, left, right):
    pivot = arr[right]  # 选最后一个元素作为 pivot
    i = left - 1        # 小于 pivot 的区域的右边界
    for j in range(left, right):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[right] = arr[right], arr[i + 1]
    return i + 1
```

**复杂度**：平均 O(n log n)，最坏 O(n²)（选 pivot 不好时），空间 O(log n)。

### 题 23：归并排序

```python
def mergeSort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = mergeSort(arr[:mid])
    right = mergeSort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

**复杂度**：O(n log n) 时间，O(n) 空间。稳定排序。

## 位运算技巧

| 技巧 | 代码 | 用途 |
|:---:|:---|:---|
| **判断奇偶** | `n & 1 == 1` | 奇数 → True |
| **清零最后一个 1** | `n & (n - 1)` | 消去最低位的 1 |
| **判断 2 的幂** | `n & (n - 1) == 0` | 2 的幂只有一个 1 |
| **取最低位的 1** | `n & -n` | 得到最低位 1 的位置 |
| **异或找唯一** | `a ^ a = 0, a ^ 0 = a` | 数组中只有一个数出现一次 |

### 题 24：只出现一次的数字

**其他数字都出现两次，找出只出现一次的数字**

```python
def singleNumber(nums):
    result = 0
    for num in nums:
        result ^= num  # 出现两次的数异或为 0，最后剩下只出现一次的
    return result
```

**复杂度**：O(n) 时间，O(1) 空间。非常优雅。

## 数据结构选型总结表

| 场景 | 推荐数据结构 | 原因 |
|:---|:---|:---|
| 需要按下标 O(1) 访问 | 数组 | 随机访问 |
| 需要频繁在中间插入删除 | 链表 | O(1) 插入删除（已知节点） |
| 后进先出（LIFO） | 栈 | 括号匹配、调用栈、撤销 |
| 先进先出（FIFO） | 队列 | 任务调度、BFS |
| 两端都要 O(1) 操作 | 双端队列 deque | 滑动窗口 |
| 按优先级出队 | 优先队列（堆） | Top-K、最短路径 |
| 快速查找/插入/删除 | 哈希表 | 平均 O(1) |
| 有序且 O(log n) 操作 | 平衡 BST / 跳表 | C++ map、Java TreeMap |
| 字符串前缀匹配 | Trie（字典树） | 自动补全、路由匹配 |
| 区间查询/更新 | 线段树 / 树状数组 | 区间和、区间最值 |
| 并查/分组 | 并查集（Union-Find） | 连通分量、Kruskal |

## 小结

面试中数据结构问题的核心规律：

**字符串/数组**：双指针（快慢指针、左右指针）、滑动窗口、前缀和

**链表**：虚拟头节点、快慢指针（判环、找中间）、递归/迭代

**栈/队列**：单调栈、单调队列、两个栈实现队列

**二叉树**：递归（90% 的问题）、BFS（层序）、中序遍历（BST）

**动态规划**：定义 dp 数组含义 → 找状态转移方程 → 确定初始条件

**排序与查找**：快速排序、归并排序、二分查找及其变种

**位运算**：异或的性质（a^a=0, a^0=a）、n & (n-1) 消去最低位的 1

**数据结构选型**：根据操作的时间复杂度需求选择最合适的数据结构

最后记住一句话：**画图画图再画图**。很多问题画个示意图，思路就清晰了。
