## 记忆口诀

**Collection 三剑?*?

- **List**：有序可重复，像排队
- **Set**：无序要唯一，像身份证号
- **Queue**：先进先出，像排队买?

**Map 选择口诀**?

- 单线程用 `HashMap`
- 要排序用 `TreeMap`
- 要顺序用 `LinkedHashMap`
- 多线程用 `ConcurrentHashMap`

## 总结

Java 集合框架分为 `Collection`（单列）?`Map`（双列）两大体系。`Collection` 下分 `List`（有序可重复）、`Set`（无序唯一）、`Queue`（队列）三类；`Map` 存储键值对，核心实现包?`HashMap`、`LinkedHashMap`、`TreeMap`、`ConcurrentHashMap`。选型时根?有序性、唯一性、线程安全、排序需?四个维度判断，日常开?`ArrayList` + `HashMap` 覆盖 90% 场景?
